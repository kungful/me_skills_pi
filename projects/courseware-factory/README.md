# 少儿美术课件工厂

一套把「一节课」变成「可售卖 PDF 课件」的生产线。
换主题只需改一个 JSON，26 页教学链条 + 17 个图片槽位全部复用。

---

## 怎么运行（最简单）

**双击 `启动审图台.bat`** → 自动打开浏览器 `http://127.0.0.1:8777`

就这一步。脚本会自动挑对 Python、缺依赖自动装。
（那个黑色窗口是服务端，**关掉它 = 关闭审图台**）

命令行等价写法：
```bash
python run_ui.py                                                # 打开第一个项目
python run_ui.py 项目/大熊猫吃竹子-4-6岁/project.json            # 指定项目
```

## 一、审图 + 改图闭环（最常用）

双击 **`启动审图台.bat`** → 浏览器自动打开 `http://127.0.0.1:8777`

界面：
- **左栏**：26 页缩略图，有问题的页显示红色角标
- **中间**：当前页大图 + 本页用到的图片卡片
- **右栏**：点任意图片卡片 → 标记状态 / 打问题标签 / 写说明 / **直接改 prompt** / 重跑
- **底部**：实时日志

按钮：
| 按钮 | 作用 |
|---|---|
| ✅通过 / ⚠️需小改 / ❌重跑 | 标记，快捷键 `1` `2` `3` |
| 🔁 重跑这张 | **只重出这一张**（约 ¥0.03），然后自动压缩 + 重装 PDF + 刷新预览 |
| 💾 保存审图 | 存进 `out/review.json` |
| 📄 导出报告 | 下载 markdown 审图报告 |
| 📂 打开输出文件夹 | 直接弹资源管理器到 `out/` |
| ⬇ 下载 PDF / PPTX | 直接下载成品 |
| 🏗 重新装配 + 导出 | 改完 JSON 或图后重出 pptx + pdf |

**成品在哪？** 就在 `项目/<课题>/out/`。顶栏那行 `📁 ...` 就是它的路径，**点一下就打开文件夹**。

### 多课件工作台（批量生产用）

顶栏 **📚 课件列表** 打开课件库浮层：

- 每套课件一张卡片：缩略图（PDF 首页）/ 名字 / 品牌 / 页数图数 / **缺图数** / 审图问题数 / 有无 PDF / 最后修改时间
- **点卡片 = 切过去**（不用重启服务），绿框 = 当前正在看，角标 = 可交付
- **勾卡片左上角复选框** → 底部选一个批量操作 → **▶ 批量执行**

批量操作：

| 操作 | 说明 | 会出图吗 |
|---|---|---|
| ① 统一品牌名 | 一次把N套的 `meta.brand` 全改掉 | 否 |
| ② 统一出图模型 | 改 `images[].model`（自动跳过别名图） | 否（只是改参数） |
| ③ 统一线条规范 | 改 `common.stroke`（全链条共用） | 否 |
| ④ 批量查找替换文案 | 递归搜页面所有文字，如“小兔子”→“小白兔” | 否 |
| ⑤ 批量重新装配+导出 | 逐套压缩 + 装配 pptx + 导 PDF | 否（用现有图） |
| ⑥ 批量仅重导 PDF | 不重新装配，只重导 | 否 |
| ⑦ 批量清空审图标记 | 重置 `review.json` | 否 |

除 ⑤⑥⑦ 外，其余操作可勾选 **“改完自动重装配+导出”**（默认勾上），改完直接拿到新 PDF。

**典型用法**：上架前品牌名还是占位符 → 打开课件列表 → 全选 → ①统一品牌名 → 勾自动导出 → 执行。N 套课件一次性全部换好并导出 PDF。

### 模型选择（15 个，下拉里带价格）

| 模型 | 价格 | 用途 |
|---|---|---|
| `gpt-image-2.5` | ¥0.03 | **默认**，过程链用它 |
| `nano-banana-2-lite` / `nano-banana-fast` | **¥0.022** | 最便宜，跑素材照片 |
| `nano-banana-2` | ¥0.06 | 稳定，2K |
| `nano-banana-pro` | ¥0.09 | 稳定性最好 |
| `gpt-image-2.5-flare` / `-sunburst` | ¥0.10 / ¥0.12 | 画质上限更高 |
| `*-cl` / `*-vip` | ¥0.30~0.90 | 稳定通道，救急用 |

⚠️ **过程链 5 步 + 成品必须同一个模型**，否则画风会不统一。

**审完直接跟我说"报告已导出"或把问题截图描述给我，我按报告改。**

## 二、做一套新课件的流程

> ★ **`pipeline.py` 和 `builder.py` 跑完会自动启动审图台并打开浏览器**，
> 并且会**自动切到刚跑完的那一套课件** —— 不用再自己去双击 bat。
> 不想让它弹（脚本/批量调用）就加 `--no-ui`，或设环境变量 `DECKUI_NO_UI=1`。

```bash
# 0. 选题 + 自检（先看爆款库里什么题材在跑量，别闭门造车）
python 工厂/选题.py --list                 # 只列候选 + 自检报告，不花钱
python 工厂/选题.py --mode pick --go       # 弹小窗由你挑 → 选完自动建脚手架
python 工厂/选题.py --go                   # 或者全自动（默认 --mode auto）

# 1. 复制结构（26页 + 16槽位全带过来，页面文案和 prompt 已标注【改我】）
python 工厂/new_project.py "小兔子吃萝卜" --age 4-6岁

# 2. 启动审图台，在右栏逐条改 prompt（或直接把 project.json 给我改）
python 工厂/server.py 项目/小兔子吃萝卜-4-6岁/project.json

# 3. 批量出图（也可以直接在 WebUI 里逐张点"重跑这张"）
#    ★ 每条命令跑完都会自动把审图台弹出来，直接看图改图
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --models   # 看模型和价格
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --list     # 看槽位和出图情况
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --batch chain
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --batch real
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --batch photo
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --batch style
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --only 范画步骤2_勾线 --force
python 工厂/pipeline.py 项目/小兔子吃萝卜-4-6岁/project.json --batch chain --no-ui  # 别弹

# 4. 装配 + 导出（装配完同样会自动弹审图台）
python 工厂/builder.py  项目/小兔子吃萝卜-4-6岁/project.json
python 工厂/exporter.py 项目/小兔子吃萝卜-4-6岁/project.json
```

### 自动弹界面的行为细节（`工厂/ui.py`）

| 情况 | 行为 |
|---|---|
| 审图台**没在跑** | 后台拉起 `工厂/server.py`（独立控制台窗口，方便你随时关），等端口就绪后开浏览器 |
| 审图台**已经在跑** | **不另起服务**（否则端口冲突 + 两份数据不同步），只把它切到刚跑完的课件，再把浏览器顶到前台 |
| 非交互环境 | 同样会弹（这正是痛点）；要静默就 `--no-ui` 或 `DECKUI_NO_UI=1` |
| 端口 | 默认 8777，可用 `--ui-port 8888` 或 `DECKUI_PORT` 改 |

> 为什么强调“切到刚跑完的课件”：服务只有一份进程，你刚给「小兔子」出完图，
> 界面却还停在上一次的「大熊猫」上 —— **看起来就像“跑完了但图没变”**。

## 三、图片全部由 AI 生成（**不再联网搜图**）

> 早期版本做过「联网搜实物照片 + 视觉复核 + 授权闸门」，**已废弃**。原因见下表——不是技术做不到，是**不划算**。

### 为什么放弃联网搜图（实测教训）

| 问题 | 实测结果 |
|---|---|
| **图文不符** | 搜索引擎按关键词返回，**图里是什么它自己不知道**。拿视觉模型复核 20 张搜来的图 → **20/20 全错**：搜「熊猫爬树」返回金毛犬，搜「大熊猫面部特写」返回花丛里的女性肖像，搜「竹子」返回穿婚纱的新娘 |
| **授权不可信** | Bing 的「可商用筛选」把**摄图网**（付费图库）也标成公版；百度/360 根本没有授权信息；pixnio 搜不到词时返回**随机图池**（垃圾词也出 48 张），照样挤占下载名额 |
| **唯一干净的源被墙** | Wikimedia Commons（真 CC + 可查元数据，本来最理想）SSL 握手超时；pixabay / openverse 403 或超时 |
| **命中率极低** | 加上视觉复核后，CC0 闸门几乎总是全挡 → 最终仍回退 AI，**白花时间** |
| **性价比** | 搜 10 个槽位 ~12 分钟（并行化后 3 分钟），省下 ¥0.3；而 AI 出图 **¥0.03/张** —— 快到根本不用省 |

### 现在的做法

**16 个槽位全部走 AI 生成**（`gpt-image-2.5` / quality `high`），换来三件事：

1. **一定对题** —— prompt 说画什么就画什么，不存在「搜到别的东西」
2. **一定能商用** —— 平台生成，无第三方版权，**不用做版权台账**
3. **风格统一** —— 与范画链同模型同线条语言，实物页和范例页不打架

成本：**¥0.03/张 × 16 ≈ ¥0.5/套**。两套课件总成本 < ¥2。

### `photos.py` 还在（可选，默认不用）

`工厂/photos.py` 保留为**独立可选工具**，自带「视觉复核」能力 —— 如果你哪天就是想要一张真实照片（自用、不卖钱）：

```bash
python 工厂/photos.py "大熊猫 坐着 实拍" "giant panda sitting" -o out.png --alt alt_dir -n 5
python 工厂/photos.py "竹子" --list          # 只列候选不下载
```

复核 API（调外部视觉模型代看，约 ¥0.0014/图）：

```python
import photos
ok, seen = photos.vcheck(open('x.png','rb').read(), '真实的竹子（竹竿和竹叶）')
# ok=True  → 对题
# ok=False → 不对题 → 淘汰
# ok=None  → 复核不可用 → 放行（绝不把好图误杀）
```

**但卖钱课件请一律用 AI 生成。**

```jsonc

            "theme": { "primary":"77A65A", "accent":"F9A605", ... } },

      "prompt":"真实的新鲜竹笋写实照片／高清实物图，褐色笋壳包着，白色背景，光线均匀，无文字水印" }
```

## 九、为什么「重跑单张」还是不像？（画过程链的原理）

这是最容易踩的坑，也是我改过的设计。先看**画过程链是怎么串参考图的**：

```
范画成品        ← 无参考（它是唯一的"标准答案"）
  ├─ 步骤1 起形  ← 参考 [成品]
  ├─ 步骤2 勾线  ← 参考 [成品, 步骤1]
  ├─ 步骤3 涂黑  ← 参考 [成品, 步骤2]
  ├─ 步骤4 上色  ← 参考 [成品, 步骤3]
  └─ 步骤5 加背景 ← 参考 [成品, 步骤4]
```

**关键：每一步都同时看到「终点」和「上一站」。**

### 早期版本的三个 bug（已修）

| # | 旧行为 | 后果 |
|---|---|---|
| ① | 步骤只参考**上一步**（成品只在步骤1的参考里） | **单链漂移**：步骤5从没见过成品，误差逐级累积，必然不像 |
| ② | 给了参考图，但没在 prompt 里**说哪张是什么** | 模型不知道要对齐谁 |
| ③ | 成品 prompt **没写线条**，步骤写 `bold clean black outlines`（实线）；成品的参考图又是封面 | **文字自相矛盾** → 成品=毛毛线、步骤=实线 |

### 现在的做法

1. **`chain.anchor`（默认=链条第一张=成品）**：链条内每张图的参考图自动变成 `[锚点, 上一步]`，锚点永远排第一。
2. **prompt 里逐张点名**：`image 1 = THE FINISHED ARTWORK ... This is the TARGET.` / `image 2 = the PREVIOUS step, continue directly from it.` 并附一段 `CONSISTENCY RULES`，锁死"同一只手画的"。
3. **`common.stroke`（线条语言）**：成品和 5 步共用**同一段文字**，字面一模一样，从源头消灭"毛线 vs 实线"的矛盾。某张图若写 `"stroke": ""` 就表示不用这套（水粉版有自己的水彩线条语言）。

### 所以：不像的时候要"重跑整条链"

在右栏选中链条里任意一张 → 点 **🔗 重跑整条链（锚点先行）**。
它会按 `成品 → 步骤1 → … → 步骤5` 顺序重跑（**成品必须先出新图**，因为后面每一步都要参考它），共 6 张 ≈ **¥0.18**。

> 单张重跑只能"往现有的成品靠"。**如果成品本身就不对，改多少单张都没用。**

### 想换线条风格？

改 `project.json` 的 `common.stroke` 一段文字即可，成品+5步同时生效。比如想要干净的实线版：
把 `breaks up into short soft HAIRY strokes` 改成 `stays one clean continuous line, no furry breaks`，
并把 `flat solid black marker fills` 保留。改完重跑整条链。
