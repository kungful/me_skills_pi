## 一、结论先行：我们的课件图为什么"不有趣"

对照 40 篇爆款，现在的 16 张图有 **4 个系统性缺陷**：

| # | 爆款在做什么 | 我们现在 | 差距 |
|---|---|---|---|
| 1 | **综合材料**：拓印 / 黏土 / 剪贴 / 海绵印章 / 棉签点彩 | 全部是"干净实线平涂"的插画 | 只有 1 种表达，40 篇里纯线描只占少数 |
| 2 | **真实感锚点**：真树叶、真卡纸、孩子举画的实拍 | 纯 AI 生成，没有"这是真的做出来了"的证据 | 这是买课件老师最想看到的 |
| 3 | **标题压在画面上**：毛笔竖排大字 / 粗体黑边大字 / 中英文双行 | 图上基本无字，标题只在版式层 | 封面点开率直接差一半 |
| 4 | **强反差设计**：明暗切割、黑×彩、白底×满构图、放射线向心 | 平铺直叙，没有"一眼抓人"的那个点 | 「最抓眼的那一点」是爆款的命门 |

## 二、7 条出图铁律（40 篇交叉验证）

1. **实物 → 几何化简形 → 平涂撞色**。几乎每篇的创作公式都从"看真东西"开始。
   动物/食物一律**几何化**（圆 + 三角 + 椭圆堆叠），不要写实。
2. **粗黑实线描边 + 平涂 + 白色高光**。高光关键词出现 12 次，是最高频的"提亮手段"。
   我们现在的"干净实线"方向是对的，**但缺"装饰填充"和"高光点"**。
3. **高饱和撞色，白卡纸底托亮**，不要莫兰迪、不要灰调。
   常见组合：橙底×黑白主体 / 红绿撞色 / 亮黄×湖蓝 / 深色底×白线。
4. **拟人化**：两个大圆眼 + 表情 + 小手小脚 + 一件道具，瞬间可爱度翻倍。
5. **画面必须有 2 种以上装饰语汇**：波点、条纹、网格、放射线、螺旋、点线面填充、拟声词气泡。
6. **至少一处"意料之外"**：剖面房间 / 立体翘起 / 可动纸条 / 超现实巨物（蘑菇长在巴士上）。
7. **加文字**：手写毛笔竖排标题 + 英文副标题 + 一枚红色小印章，剪贴感。

## 三、6 个可直接用的风格配方（爆款验证过的）

> 这是要写进 `project.json` 的 `common.style_preset` 的六个值。

### 1. `marker_flat`　马克笔平涂撞色（**最主流，出现率最高**）
- 材料：白卡纸 + 马克笔 + 黑色勾线笔 + 白色高光笔
- 笔触：粗黑实线描边 → 高饱和平涂（无渐变）→ 白色高光点 / 内部花纹填充
- 配色：白底 + 3 个高饱和主色撞色
- 装饰语汇：波点、条纹、网格、螺旋
- 公式：`实物照片 → 几何化简形 → 粗线勾边平涂 → 内部填花纹 → 白高光提亮`
- 参考爆款：煎蛋(5701)、植物甲虫(4711)、七星瓢虫(1116)、胡萝卜(3198)

### 2. `collage_mixed`　综合材料拓印拼贴
- 材料：真实树叶 / 保鲜袋 / 海绵印章 / 棉签 + 水粉 + 卡纸剪贴
- 笔触：拓印颗粒肌理、羽化粉末感、点按重复母题
- 配色：彩虹色渐变排布
- 公式：`自然实物 → 垫纸拓印留肌理 → 同形多色排成一列 → 剪贴/高光点睛`
- 参考爆款：树叶拓印(11545)、吸管小雏菊(4509)、保鲜袋拓印(1106)、海绵睡莲(2117)
- ⚠️ 这个风格**最能打动买家**，但 AI 最难生成得像"真做过"——建议配合真实材料实拍的版式位。

### 3. `darkline_doodle`　黑白线描 × 单色底
- 材料：黑卡纸 / 单色圆底 + 白色高光笔 + 勾线笔
- 笔触：粗黑线描 + 点线面装饰填充，无彩色
- 配色：**黑白高反差** + 一个暖色点缀
- 公式：`实物 → 几何化轮廓 → 黑白线描 + 点线面纹理填满 → 单色圆底衬色 → 粗黑标题剪贴`
- 参考爆款：植物甲虫(4711)、线描植物(2471)、粉笔海洋世界(1126)

### 4. `gradient_dot`　点彩晕染梦幻（莫奈系）
- 材料：水粉/丙烯 + 圆头笔 + 棉签 + 海绵 + 旧牙刷
- 笔触：蓝绿渐变晕染铺底 → 点画主体 → 牙刷弹洒白色星点
- 配色：蓝绿渐变 + 白色高亮，清透不刺眼
- 公式：`名画主题 → 渐变晕染铺底 → 圆头笔点画主体 → 亮色小花点睛 → 弹洒星光`
- 参考爆款：莫奈睡莲(2117)、秋天的树(6453)

### 5. `clay_relief`　黏土半立体手工
- 材料：超轻黏土 + 彩卡纸 + 马克笔
- 笔触：搓条/搓球压贴出体积，画面有真实阴影
- 公式：`主题 → 卡纸拼贴底 → 黏土搓球堆叠体积 → 平涂五官 + 粉腮 → 实物道具点缀`
- 参考爆款：可爱的小羊(1262)、豆角(957)

### 6. `chalk_board`　黑板粉笔
- 材料：黑板绿底 + 白色/彩色粉笔
- 笔触：白色单线勾勒 + 点线面排线纹理，粉末感
- 配色：黑板绿底 + 粉笔白，高对比
- 公式：`深色底 → 白色线描主体 → 同类实物简形排列 → 点线面纹理填充 → 角落手写主题词`
- 参考爆款：粉笔画(1126)

## 四、封面（P1）必须单独做

爆款封面**和内容页不是一回事**，四个高频封面套路：

1. **四宫格拼贴**：成品 + 孩子举画实拍 + 过程照 + 局部特写（出现 3 次，均在头部）
2. **实物拓印成品 + 真人笑脸**
3. **满构图成品 + 居中/竖排毛笔大字标题**
4. **黑白线描成品 + 高饱和圆底**（强反差）

→ 封面 prompt 应该额外加：`poster-style composition, big handwritten Chinese title area, willing to be cropped to 3:4`。
