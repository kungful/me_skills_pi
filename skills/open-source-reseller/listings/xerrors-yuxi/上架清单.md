# 闲鱼上架清单（全人工 · 保号优先）

> 原则：**这条链路一个自动动作都不做。** 闲鱼对虚拟商品的判定看的是行为序列，
> 脚本发布/批量改价/多号铺同款都会连带整个支付宝实名下的账号。人工 5 分钟能做完的事，不值得赌一个月。

## 一、上架前必须有的东西（缺一条别点发布）

- [ ] **自己真跑通过一次**（干净机器，照文档从零，含踩坑记录）——这是能卖的底线
- [ ] 商品图 3 张以上：首图（成品界面）+ 能干什么 + 交付清单 ← `kit/img/` 已有 2 张，缺"成品界面实拍"
- [ ] 标题 ≤30 字，含真实搜索词 ← `kit/xianyu.md` 已有
- [ ] 详情写清：拿到什么 / 不含什么 / 跑通再确认收货 ← 已有
- [ ] 三档定价想好：39 引流 / 199 主推 / 699 定制 ← 已有
- [ ] 交付物打包成一个压缩包，含 LICENSE 原文与原作者署名
- [ ] 售后边界写死：含 1 次修改、不含上游大版本变更适配

## 二、上架动作（手动，5 步）

1. 手机闲鱼 → 卖闲置 → 选「技能服务 / 其他」类目（别选普通商品）
2. 传图：顺序 `01_主图` → `02_服务清单` → 成品界面实拍
3. 粘贴标题（27 字那条），粘贴详情，价格填 199
4. 位置填自己所在城市（同城曝光有用），发布
5. 发布后**不要立刻改价、不要反复编辑**——隔 24h 再调

## 三、每天的动作（稳定 > 冲量）

| 时段 | 做什么 | 上限 |
|---|---|---|
| 上午 | 回私信：先问环境（服务器/本机、系统、资料量），隔 1–3 分钟再发 | — |
| 中午 | 擦亮（闲鱼自带功能，手点） | 1 次/天 |
| 晚上 | 看曝光数据，只记不改 | — |

- 每天最多**新发 1 条**（同款不许多号铺，不许删了重发）
- 一周内不追爆量，先把第一个成交跑完

## 四、保号红线（碰一条就白干）

1. 详情/聊天里**不出现微信、QQ、vx、加我、站外链接**
2. 不写「包过 / 保证永久 / 无限修改 / 官方授权」
3. 一个平台一个真人老号，不做多开/群控/指纹伪装
4. 不搬运别人的图和文案（闲鱼有图搜判重）
5. 纠纷优先退款换好评，别跟买家硬顶
6. 不把免费开源说成自研——商品页写明「基于 XX 封装」，这句话同时是免责和背书

## 五、成交后（10 分钟内做完）

- [ ] 交付包发出，附 LICENSE 原文
- [ ] 约远程时间，跑通后让客户自己点确认收货（别催）
- [ ] 截一张「客户验收通过」的对话图存进素材库
- [ ] 问一句「还有哪里想改」——复购入口
- [ ] 台账更新：`python sourcing.py ledger set xerrors-yuxi xianyu live`

## 六、闲鱼没有的（别指望）

- 没有开放 API，搜索都要登录 → 定价调研、竞品分析全人工
- MCP 里没有任何闲鱼工具，且**不建议加**：自动发布是这类平台最先抓的行为
- 虚拟商品不支持"包退"承诺，别写
