# Style Directions

These are optional starting points. Choose a visual treatment that fits the project's audience, identity, and message; a direction outside this list may fit better.

Start with useful visual references from the project. If its existing images do not fit the preview, develop a relevant idea from its purpose, examples, or domain. Choose how to style that material separately. Typography, a symbol, an illustration, an interface, an output, or a sequence can each work. Use a workflow only when the steps are central to the message. See [examples.md](examples.md) for two project-specific references.

## Retro editorial

Use flat color fields, bitmap or pixel-display typography, hard-edged shadows, and asymmetric magazine-like composition. Use illustrations, screenshots, or code fragments when they suit the project. Keep the image graphic and mostly two-dimensional.

Example: [Open SaaS artwork and attribution](examples.md#open-saas-retro-editorial).

Avoid gradients, glossy 3D objects, generic dashboards, and fake terminal decoration.

## Swiss technical

Use oversized modern typography, a strict modular grid, generous negative space, and thin rules. A focused typographic composition can stand alone; add a symbol, diagram, or screenshot only when useful. Limit the palette to neutral paper or ink plus one signal color.

Avoid centered hero layouts, soft blobs, glassmorphism, and ornamental icons.

## Terminal collage

Build the card from one real or truthful terminal interaction, a source-owned UI fragment, and restrained annotations. Use monospaced type, hard crops, high contrast, and visible command-to-result causality.

Avoid walls of fake code, matrix rain, green-on-black nostalgia, and screenshots too small to read.

## Diagrammatic print

Explain one transformation using a technical-manual or risograph-like diagram: input, mechanism, and output. Use flat arrows, numbered callouts, simple geometry, slight print texture, and a limited ink palette.

Avoid luminous portals, volumetric light, holograms, floating cards, and generic network graphs.

## Selection rule

Choose the direction whose medium reinforces the message. For example:

- retro editorial can suit a playful or opinionated project;
- Swiss technical can emphasize clarity and precision;
- terminal collage can fit a project whose command or output is worth showing;
- diagrammatic print can help when explaining a transformation is the main message.

If two directions are plausible, propose both in words and recommend one before generating. Do not generate multiple variants unless the user asks.
