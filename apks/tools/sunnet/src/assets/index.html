电压怎么分 哪一层用多少 V

电源怎么走 先搭电，再上信号

【12V 母线】12V 电源 ─┬─ 3A 保险 ─┬─ 急停常闭(硬断电) ── MOS 开关模块 ── DRV8871 VM
                      │            └─ LM2596 降压 ── 【5V】── 开发板 5V/VIN
                      └─ GND ───────────────────── 所有模块 GND 共地

【5V】  LM2596 输出（空载先调到 5.0V 再插板子）
【3.3V】开发板 3V3 脚 ── 光敏 VCC / 雨滴 VCC / 电位器两端 / ACS712(3.3V 版)
【干接点】限位A 限位B / 急停 / 风速开关 / 旋钮 / 按键  ── 一端 GPIO、一端 GND

DRV8871  OUT1 ── 网机(电机) 一根线          ┐ 12V 换向
DRV8871  OUT2 ── 网机(电机) 另一根线        ┘
急停按钮【第一组常闭】串在 12V → MOS 开关 之间（硬断电）
急停按钮【第二组常闭】接 GPIO12（固件回读）

接线表 板上位号 → 模块 → GPIO → 电压
