## 0. 你需要准备什么

| 工具 | 为什么必须 |
|---|---|
| **万用表**（带直流电压档、通断/电阻档） | 没它别上电。整个流程一半时间在量电压 |
| 小十字 / 一字螺丝刀 | 拧端子 |
| 剥线钳 + 剪刀 | 剥皮 |
| 杜邦线（母-母 40P）和 0.75mm² 红黑电源线 | 信号线 / 电源线 |
| 压线端子 或 直接拧紧端子 | 电机、电源这种大电流线 |
| 热缩管 / 电工胶布、扎带 | 防短路、理线 |
| 烙铁（可选） | 只有 LED 和 1k 电阻可能需要焊一下 |

**不会烙铁怎么办**：LED 和按键可以先不接（不影响自动收放功能）；
或者买"已焊好线、带端子"的模块版本。

## 1. 先记住这 5 条铁律

1. **任何接线、改线之前，先拔掉 12V 电源。** 接完先用万用表量一遍再上电。
2. **+12V 线上必须串 3A 保险丝**（靠近电源那一端），不要装在地线上。
3. **所有模块的模拟输出只能 3.3V。** 光敏模块、雨滴模块一律用 **3V3** 供电；
   如果给它们 5V，AO 会输出 5V，**直接烧掉 ESP32 的 ADC 脚**。数字量（按键/限位/开关）无所谓。
4. **所有模块的 GND 必须接到一起**（一点共地）。包括 ESP32、MOS、DRV8871、LM2596、
   所有传感器和开关。**不共地 = 信号乱跳 = 乱收网。**
5. **先只接电源、量完电压，再插 ESP32。** 反接电源会瞬间烧模块。

## 2. 第一步：电源（看图 `2-电源`）

### 接线（正极走红、地线走黑）

| 从 | 到 | 线色 |
|---|---|---|
| 12V 电源适配器 `+12V` | 保险丝座 `IN` | 红 |
| 保险丝座 `OUT` | 接线端子排 `+12V 排` | 红 |
| 接线端子排 `+12V 排` | MOS 开关模块 `VIN+` | 红 |
| 接线端子排 `+12V 排` | LM2596 模块 `IN+` | 红 |
| MOS 开关模块 `VOUT+` | DRV8871 模块 `VM` | 红 |
| DRV8871 模块 `OUT1` | 电机 线① | 红 |
| DRV8871 模块 `OUT2` | 电机 线② | 蓝 |
| LM2596 模块 `OUT+` | **ESP32 的 `5V` 脚** | 橙 |
| 12V 电源适配器 `GND` | 接线端子排 `GND 排` | 黑 |
| MOS 开关模块 `VIN-` | 接线端子排 `GND 排` | 黑 |
| LM2596 模块 `IN-` | 接线端子排 `GND 排` | 黑 |
| LM2596 模块 `OUT-` | **ESP32 的 `GND` 脚** | 黑 |
| DRV8871 模块 `GND` | 接线端子排 `GND 排` | 黑 |
| **所有传感器 / 开关的 GND** | 接线端子排 `GND 排` | 黑 |

> **没有 "中线端子排" 怎么办？** 找一块小接线端子（KF301 / 接线端子排都行），
> 或者把所有该接 +12V 的线拧在一起用一根粗线引出来。端子排只是让线更好理、好查。

### 上电顺序（**一定按这个来**）

1. 把 12V 适配器、保险丝、端子排、LM2596 先接好，**ESP32 先不插**。
2. 万用表**直流电压档**：端子排 `+12V 排` 对 `GND 排` → 应在 **12V 左右（±0.5V）**。
3. 拧 LM2596 上的蓝色小电位器，让 `OUT+` 对 `OUT-` 正好 **5.0V**（4.9~5.1 都行）。
4. 确认后，才把 LM2596 的 `OUT+` → ESP32 `5V`，`OUT-` → ESP32 `GND`。
5. 现在才插上/打开 12V 电源，ESP32 上的电源灯应该亮。

### 常见错误

- **正负极接反** → 瞬间烧模块。接完**再量一遍**。
- 12V 适配器电流 < 3A → 电机一启动就"打嗝"重启。要用 **≥3A**（户外用 5A 防水）。
- 用 USB 给 ESP32 烧程序时，**把 12V 电源关掉**（两路电源同时灌虽然一般没事，但别赌）。
- 户外长时间用：换 12V/5A 防水电源（IP67），并加**直流防雷器**。

## 3. 第二步：电机（看图 `3-电机`）

**为什么要有 MOS 模块？** 它是整条电机母线的"总闸"。只有固件把 `IO6` 拉高，
电机才有电；不动作时母线自动断电（默认关断），这是防意外转动的第一层保险。

| ESP32 脚 | 接到 | 说明 |
|---|---|---|
| `IO6` | MOS 开关模块 `SIG`（触发输入） | **拉高 = 母线带电**；不拉高电机永远不转 |
| `IO4` | DRV8871 模块 `IN1` | 方向 1 |
| `IO5` | DRV8871 模块 `IN2` | 方向 2 |
| `GND` | MOS 开关模块的信号地（如有 `GND`/`GNDD` 脚） | 信号要共地 |
| 端子排 `+12V 排` | MOS `VIN+` | 12V 进 MOS |
| 端子排 `GND 排` | MOS `VIN-` | 12V 地 |
| MOS `VOUT+` | DRV8871 `VM` | 受控的 12V 出 |
| MOS `VOUT-` | DRV8871 `GND` | 同一条地 |
| DRV8871 `OUT1` / `OUT2` | 电机两根线 | **无极性**，接反只是方向相反 |

**MOS 模块 3.3V 触发不灵怎么办？** 有些模块要求 5V 触发信号。加一级电平转换：

```
IO6 ──1kΩ──> S8050 三极管 基极
             发射极 ──> GND
             集电极 ──> MOS 的 SIG
             MOS 的 SIG 再经 10kΩ 上拉到 +5V
```

小信号三极管 S8050（NPN）+ 2 个电阻，一两块钱的事。

**DRV8871 的 IN1/IN2 是 3.3V 逻辑，可以直接接，不需要转换。**

## 4. 第三步：安全链（看图 `4-安全链`）

> **好消息**：散装版**不需要外接任何上拉电阻**。固件在散装模式下改用了芯片内部
> 上拉/下拉（打样板才靠板上的 10k 电阻）。

### 4.1 限位开关 ×2（展开终点 / 收网终点）

| 开关的脚 | 接到 |
|---|---|
| `NO`（常开） | ESP32 `IO7`（限位 A）/ `IO11`（限位 B） |
| `COM`（公共） | GND |
| `NC`（常闭） | **空着不接** |

- 开关上一般标着 `COM` / `NO` / `NC` 三只脚。**用 COM 和 NO，NC 空着。**
  用 NC 会反：不触发反而读成"触发"。
- 触发时（机构压到限位）触点闭合到 GND，固件读成"触发"。

### 4.2 急停按钮（必须常闭 NC）

| 急停的脚 | 接到 |
|---|---|
| `COM`（公共） | **3V3** |
| `NC`（常闭） | ESP32 `IO12` |

- **这里接 3V3，不是 GND**，因为要"失效安全"：正常时回路闭合 = 高电平 = 正常；
  **按下 或 线断了** → 变低 = 急停。断线也能停机，这就是常闭回路的意义。
- 一上电如果就报急停：说明线没接好（它默认"断线=急停"）。
  临时可以 `set hwEstopEnabled 0` 跳过，但**正式使用一定要接好**。

### 4.3 手动/自动 旋钮

| 旋钮的脚 | 接到 |
|---|---|
| `COM`（公共） | ESP32 `IO13` |
| 手动那一档 | GND |
| 自动那一档 | **空着不接**（悬空 = 内部上拉 = 自动） |

拨到手动档时，固件会**强制停掉自动跟踪**，并且拒绝 `mode auto` 命令（拨杆优先）。

## 5. 第四步：传感器 + 面板（看图 `5-传感器与面板`）

| 模块 | 怎么接 |
|---|---|
| **光敏电阻模块** | `VCC`→**3V3**，`GND`→GND，`AO`→`IO1`（`DO` 空着） |
| **雨滴模块 YL-83** | `VCC`→**3V3**，`GND`→GND，`AO`→`IO2`（`DO` 空着） |
| **风速开关** | 两线无极性：一线→`IO14`，另一线→GND |
| **三杯式风速计（脉冲型，可选升级）** | 见下面 §5.1 + 图 6 |
| **10k 多圈电位器** | 脚1→3V3，**脚2（中点）→`IO3`**，脚3→GND |
| **按键 MODE** | 一脚→GND，另一脚→`IO21` |
| **按键 CW（展开）** | 一脚→GND，另一脚→`IO38` |
| **按键 CCW（收网）** | 一脚→GND，另一脚→`IO39` |
| **LED1（运行/故障）** | `IO47` →**1kΩ 电阻**→ LED 长脚(+)；LED 短脚(-) → GND |
| **LED2（电机动作）** | `IO48` →**1kΩ 电阻**→ LED 长脚(+)；LED 短脚(-) → GND |

**要点**

- 光敏 / 雨滴模块一般 4 个脚：`VCC` `GND` `DO` `AO`。**我们只用 VCC、GND、AO。**
- **LED 一定要串 1kΩ 电阻**，直接接会烧 IO 口。
- 雨滴模块那块裸露的探头小板**不要长期露天裸放**（几天就氧化）。户外改用
  **带加热的雨雪传感器**，或者只在雨天才把探头装上。
- 风速开关要装在**没有遮挡、也不会被网自己挡住**的地方。
- 电位器装反只是"光越强越展开"变成反的，可以用 `set thUp / thDown` 改成绝对阈值兜底。

### 5.1 可选升级：三杯式风速计（按真 m/s 收网）

风速开关只能告诉你"有风/没风"。想按 **8 m/s 收网** 就得换三杯式**脉冲**风速计，
接线见 **图 6**，要点就两条：

| 风速计的线 | 接到 |
|---|---|
| `电源+`（红） | 端子排 `+12V`（**电压看铭牌**，常见 12V/24V，不要用 ESP32 的 3V3） |
| `GND`（黑） | 公共地 |
| `脉冲`（黄/绿） | `IO14`，**并加一个 4.7kΩ 上拉到 3V3** |

⚠️ **接之前先用万用表确认输出类型**：

- 不转时量"信号对 GND"≈3.3V，用手转风杯时被拉低 → **集电极开路 / NPN** → 可以按上图直插；
- 若量到 **5V 或 12V 的电压脉冲** → 必须先分压或加光耦隔离，**否则会烧掉 IO 口**。

接好之后：

```
① set windMode 1                    # 切成脉冲模式（状态页会出现 wind.hz / wind.mps）
② 看看 wind.hz（比如 12.3 Hz）
③ 对照手机天气/附近气象站的风速（比如 9.0 m/s）
④ windMpsPerHz = 9.0 ÷ 12.3 × 100 ≈ 73   →  set windMpsPerHz 73   （多测几次取平均）
⑤ set windStartMps 80               # 8.0 m/s 收网
  set windStopMps 50                # 5.0 m/s 解除（时间滞回之外的第二层硬件滞回）
  set windEmergMps 120              # 12.0 m/s 紧急：不等确认时间，立即收网
```

（`windStartMps / windStopMps / windEmergMps` 的单位都是 **0.1 m/s**。）

## 7. 上电检查清单（每一条都打勾再下一步）

```
[ ] 目视：没有裸铜线互相碰到；每个端子螺丝都拧紧（轻拉线不脱）
[ ] 断电，万用表电阻/通断档：端子排 +12V 对 GND，**不响**（没短路）
[ ] 只上 12V，量端子排：+12V 对 GND ≈ 12V
[ ] 量 LM2596：OUT+ 对 OUT- = 5.0V（拧电位器调）
[ ] 量 MOS VOUT+ 对 VOUT- ：应为 0V（此时 IO6 还没拉高）
[ ] 插上 ESP32，12V 上电：板上电源灯亮
[ ] 手机搜到热点 pcbsun-XXXX（密码 pcbsun1234）
[ ] 打开 http://192.168.4.1/ ，能出控制页
[ ] 状态页里 light / pot / rain 的 raw 是 0~4095 中间的值（不是 0，也不是 4095）
[ ] 用手压限位 A → 状态页 limits.a 变 true（压 B → limits.b 变 true）
[ ] **拔掉急停那根线 → estop 变 true**（这一步是验证失效安全，必须做）
[ ] 点 JOG CW / CCW：电机转；松手后停（MOS 母线随后自动断电）
```

任何一条不过，先别继续，见下面的排查表。

## 8. 上电之后怎么干线

```bash
cd pcbsun-esp32s3
pio run -e esp32s3-scatter -t upload      # 烧固件
pio run -e esp32s3-scatter -t uploadfs    # 烧网页（不做这步浏览器打开会 404）
```

然后按这个顺序联调：

1. **空载跑一次全程**：网页/App 里点 `deploy`（展开），看它走到 A 限位自动停；
   点 `stow`（收网），走到 B 限位自动停。限位方向反了，就把
   `limitAStopsCw` / `limitBStopsCcw` 对调。
2. **设阈值**：网页设置页里有全部参数。常用几个：
   - `thHyst`（迟滞）、`nightLight`（夜晚阈值）→ 让白天/夜晚判断正确
   - `windConfirmMs`（大风确认，默认 3000ms）、`rainConfirmMs`（降雨确认，默认 2000ms）
   - `windClearMs`（风停解除延迟，默认 30000ms）→ 三个一起构成"防误动作"时序
   - `retractCooldownMs`（收网后冷却，默认 600000ms=10 分钟）
   - `retractMaxMs`（走限位超时，默认 60000ms）、`travelRetryMax`（超时重试次数，默认 1）
3. **挂真网跑一次**，用**钳形表或串在电源里的万用表**量电机实际电流，
   再 `set stallMa 800`~`1200`、`set imonEnabled 1` 打开堵转保护。
   （装 ACS712 的话先 `set imonZeroMv 2500`。）
4. 最后把电箱盖好、做好防水，线用扎带固定。

## 9. 出问题怎么查

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 电机完全不转 | `IO6`/MOS 没接通；MOS 要 5V 触发；12V 没到位 | 量 MOS `VOUT+` 对地：点 JOG 时应有 12V；没有就查 IO6 和 MOS SIG |
| 电机转但方向固定、换向无效 | `IN1`/`IN2` 接错了或有一根没接 | 量 DRV8871 的 IN1/IN2 在 JOG 时的电平，应该一个高一个低 |
| 一上电就 `fault: estop` | 急停没接／接到 GND 了／用了 NO | 接 `3V3→COM，NC→IO12`；临时 `set hwEstopEnabled 0` |
| 一上电限位就是 `true` | 用了 NC 触点；或 COM/NO 接反 | 改用 `COM` + `NO` |
| 传感器数值乱跳 / 一会儿有雨一会儿没雨 | **没共地** | 把所有 GND 接到同一根/同一个端子排 |
| `light` 或 `pot` 读到 4095 不动 | 模块用了 5V 供电；或开路 | 改 3V3；检查 AO 是否接在 `IO1`/`IO3` |
| 浏览器打开 `192.168.4.1` 是 404 | 忘了烧文件系统 | `pio run -e esp32s3-scatter -t uploadfs` |
| 网页/热点搜不到 | 没插好／供电不足 | 量 ESP32 的 `5V` 脚应为 5V；重新上电 |
| 旋钮方向反了 | 手动/自动极性反 | `set modeSelManualLow 0` |
| 走限位总走不到、最后报 `deadlock` | 限位线没接好；机构卡住 | 查限位接线；机构问题先解决机械再上电 |
| 一收网就马上又展开（来回摆） | 没设冷却/滞回 | 设 `retractCooldownMs`、`windClearMs`、`thHyst` |
