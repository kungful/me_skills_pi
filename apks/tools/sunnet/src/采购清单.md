# 太阳网（风光雨自动控制）—— 现成散装模块采购清单

> 目标：**不做 PCB、不做 SMT**，全部买现成模块用端子/杜邦线接起来，
> 功能与嘉立创工程 `pcbsun` 那块板一致；**固件用同一套**（只改引脚表），
> 所以手机上已经装好的 `com.hua.sunnet`（太阳网控制器 APK）直接就能用。
>
> 价格是 2026 年淘宝散件常见区间（含运费前后波动），按「中位价」估。
> 下单前请按「搜索关键词」自己比价——同款差价能到 2 倍。

---

## 0. 一句话结论

| | 自制 PCB（现在的路线） | 散装模块（本清单） |
|---|---|---|
| 一次投入 | **¥450 ~ 800**（打样 + 钢网 + SMT 起订 + 105 个位号元件） | **¥220 左右**（方案 A） |
| 到货 | 打样 3-5 天 + 贴片 3-7 天，改一版再等一轮 | 当天 ~ 3 天，坏了换一块 |
| 风险 | 钢网/贴片起订量、虚焊、天线禁布、改版重来 | 插错一根线，重插 |
| 灵活性 | 改一个脚就要重画 | 想加传感器就再买一个模块 |
| 体积 | 125×90 mm 一块板，漂亮 | 接线盒里一堆模块，丑但能装 |

**结论：第一版先用散装模块把功能跑通（省钱、快、可改），跑顺了再考虑做板。**

## 无 PCB，怎么接（方案 A 接线表）

```
12V 电源 ─┬─ 3A 保险 ─┬─ MOS 开关模块 VIN(+) ── MOS 输出 ── DRV8871 模块 VM
          │            └─ LM2596 降压 ── 5V ── ESP32 开发板 5V/VIN
          └─ GND ────────────────────────── 所有模块 GND 共地

DRV8871 模块  OUT1 ── 网机(电机) 一根线
DRV8871 模块  OUT2 ── 网机(电机) 另一根线
DRV8871 模块  GND  ── 电源 GND
```

| 板上位号 | 散装模块引脚 | 接到 ESP32-S3 开发板 | 备注 |
|---|---|---|---|
| U3 IN1 | DRV8871 模块 IN1 | GPIO4 | PWM 输出 |
| U3 IN2 | DRV8871 模块 IN2 | GPIO5 | PWM 输出 |
| Q4 栅极 | MOS 开关模块 信号输入 | GPIO6 | 高电平 = 母线带电 |
| J8 限位A | 限位开关 一端 | GPIO7 | 另一端接 GND |
| J9 限位B | 限位开关 一端 | GPIO11 | 另一端接 GND |
| J10 急停 | 急停按钮 常闭 一端 | GPIO12 | 另一端接 GND |
| J11 模式 | 旋钮开关 公共端 | GPIO13 | 档位端接 GND；拨到手动档拉低 |
| J4 光照 | 光敏模块 AO | GPIO1 | **必须 ADC1（GPIO1-10）** |
| J7 雨 | 雨滴模块 AO | GPIO2 | 雨模块请用 **3.3V** 供电 |
| J5 风 | 风速开关 一端 | GPIO14 | 另一端接 GND |
| R13 设定点 | 电位器 中间脚 | GPIO3 | 另外两脚接 3V3 与 GND |
| U7 电流 | ACS712 模块 OUT | GPIO8 | 可选，不装就把 `imonEnabled` 设 0 |

**⚠ 两条硬性注意：**
1. **模拟量只能用 GPIO1–GPIO10（ADC1）**。ESP32-S3 的 ADC2 一开 WiFi 就读不准，
   板子原设计就是按这个来的。
2. **模块的模拟输出不要超过 3.3V**。雨滴模块、光敏模块如果用 5V 供电，AO 能到 5V，
   直接接进 ESP32 会打坏 ADC 脚 —— 所以统一 **3.3V 供电**，或加 10k/20k 分压。

## 固件怎么复用（同一套代码，只改一张引脚表）

固件 `pcbsun-esp32s3/` 里的 `include/board.h` 把引脚写成了常量，改这几行就行：

```cpp
// ---- 散装模块版引脚表（对照上面接线表）----
constexpr int MOTOR_IN1   = 4;
constexpr int MOTOR_IN2   = 5;
constexpr int MOT_EN      = 6;
constexpr int LIMIT_A     = 7;
constexpr int LIMIT_B     = 11;
constexpr int ESTOP_SENSE = 12;
constexpr int MODE_SEL    = 13;
constexpr int IMON_ADC    = 8;
constexpr int LIGHT_ADC_DEFAULT = 1;
constexpr int RAIN_IN_DEFAULT   = 2;
constexpr int POT_IN_DEFAULT    = 3;
constexpr int WIND_IN_DEFAULT   = 14;
constexpr int BTN_MODE = 21;
constexpr int BTN_CW   = 38;
constexpr int BTN_CCW  = 39;
constexpr int LED_RUN   = 47;
constexpr int LED_MOTOR = 48;
// 电流换算改成 ACS712-20A：100 mV/A ⇒ 0.1 mV/mA
constexpr float IMON_GAIN      = 1.0f;
constexpr float IMON_SHUNT_OHM = 0.100f;
```

其余照旧：
```bash
pio run -t upload          # 烧固件
pio run -t uploadfs        # 烧 WebUI（不做这步浏览器打开会 404）
```
**手机的 App 不用改**：热点名、密码、BLE 服务 UUID、JSON 协议全都一模一样。

> 想省事也可以不装限位/急停/电流：把 `limitEnabled`、`hwEstopEnabled`、`imonEnabled`
> 设为 0 就能跑，但**没有限位就不允许 deploy/stow**（固件故意这么设计的，防止把网拉到底）。
