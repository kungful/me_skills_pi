# 棚架受力分析（CanopyStruct）

> L 形砖墙内角 + 三根贴墙立柱 + 镀锌管焊接三角挑梁 + 太阳网 —— 受力 / 风荷载 / 基础抗拔的
> 三维可视化分析工具。**不是有限元软件，也不替代结构工程师**，它给的是量级和方向。

Android APK：`棚架受力分析.apk`（21 个文件，约 260 KB，纯离线，无网络权限）
包名：`com.hua.canopystruct`

---

## 它能回答的问题

- 这片 32 m² 的太阳网，风一吹到底往上提多少公斤？
- 三根 Φ89 镀锌管 + 一些膨胀螺栓，能扛几级风？（**答案：约 5 级**）
- 加柱 / 换厚管 / 加大基础 / 大风前收网，哪个最有用？（**答案：收网 > 加柱 > 换管 ≈ 加大基础**）
- 上斜拉（拉索）在哪种工况下会失效？（**答案：风压向下，拉索受压直接退出**）
- 要多大的独立基础才压得住？（**自动找方案**功能会扫出来）

## 力学模型

| 部分 | 做法 |
|---|---|
| 风荷载 | `w_k = β_gz·μ_z·μ_s·w_0`，GB 50009-2012 体系；μ_z/β_gz 按 A/B/C/D 粗糙度表对数插值；μ_s 按网布透风率折减 |
| 三个工况 | ① 风吸上抬 ② 风压向下 ③ 水平风。**风吸工况按“砖墙不参与”计算** |
| 杆系内力 | 平面直接刚度法（矩阵位移法）：节点 3 自由度、2 节点 6 自由度梁单元；端部释放用静力凝聚；拉索用“仅受拉迭代”（受压就退出重算） |
| 构件校核 | `σ = N/(φA) + M/W ≤ f`、`τ ≈ 2V/A ≤ f_v`、`δ ≤ L/150`；稳定系数按欧规 b 类曲线（≈ GB 50017 b 类） |
| 柱脚/基础 | 锚栓 `T = M/a − N/2`、抗拔 `K = G/N ≥ 1.5`、绕边抗倾覆 `K = G·B/2 / (N·(L−B/2)) ≥ 1.5`、地基压力 `p_max ≤ f_a` |
| 反算 | 二分法求“强度利用率 = 1.0”对应的风速 → **这套方案能扛几级风** |

## 构建

```bash
bash build.sh        # 只打包（含 node 力学自测，不过就中止）
bash build.sh -i     # 打包 + adb 安装到手机 + 启动
```

只用 Android SDK build-tools（aapt2 + javac + d8 + zipalign + apksigner），不联网、不用 Gradle。

## 测试

```bash
node tools/selftest.js                    # 与解析解对比：悬臂/简支/固端/桁架/斜撑悬臂/风荷载/整体模型

```

自测覆盖：悬臂梁 `PL³/3EI`、简支梁 `5wL⁴/384EI`、固端梁 `wL²/12`、桁架轴力 `P√2/2`、
斜撑悬臂柱底弯矩 `P·L`、拉索受压自动退出、β_gz/μ_z 查表、整体模型数值健全性。

## 已知的简化（重要）

- 没有整体空间三维分析；每个柱-挑梁按平面刚架单独算，柱子之间靠分担宽度分配荷载。
- 节点按刚接处理，没有考虑真实焊接节点的半刚性。
- 没有二阶效应（P-Δ）、没有网面张拉找形、没有风振。
- 体型系数是工程近似，不是风洞数据。
- 土参数（承载力、地下情况）必须现场确认。
