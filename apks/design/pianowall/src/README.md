# 钢琴墙 · 3D 演示 APK（PianoWall）

给「两面 10 m 长、2 m 高的墙，90° 相接，拼成钢琴键盘图案」做的一个**安卓 App**：
三维演示 + 全套带尺寸的施工图纸 + 参数化改尺寸，全部离线可用（无网络、无第三方 App 依赖）。

- APK：`PianoWall.apk`（约 220 KB，minSdk 29 / Android 10 及以上）
- 包名：`com.hua.pianowall`　应用名：钢琴墙 3D
- 预览图：`预览图/` 目录（3D 五个视角 + 四张图纸）

## 一、图案尺寸（默认值，即图纸值）

| 项目 | 尺寸 | 说明 |
|---|---|---|
| 单面墙长 × 高 | **10 000 × 2 000 mm** | 两面墙相同 |
| 两面墙总展开长 | **20 000 mm（20 m）** | 立面面积 40.00 m² |
| 转角 | **90°** | 两面墙键面朝内院，转角处各自从整键起排（左右对称） |
| 墙体（面板）厚度 | 120 mm | |
| 白键宽（= 分块宽） | **500 mm** | 每面墙 20 块，两面共 **40 块** |
| 黑键宽 | **295 mm** | 白键的 59.0%（真钢琴为 58.3%） |
| 黑键高（自墙顶往下量） | **1 300 mm** | 墙高的 65%（真钢琴约 63%） |
| 黑键下沿离地 | 700 mm | |
| 底部黑踢脚带 | **150 mm** | 通长，两面墙各一条 |
| 白键板净高 | 1 850 mm | 2 000 − 150 |
| 键板拼缝 | 8 mm | 缝后必须做深色背板 |
| 黑键 / 踢脚凸出 | 25 mm | 靠投影产生立体感 |
| 一个八度（7 个白键） | 3 500 mm | 两面墙各 2 组余 6 键 |
| 黑键数量 | **每面 14 条，两面 28 条** | |

### 排布规则
白键按 500 mm 等宽排布，**每 7 个白键为一个八度**；黑键落在每组第 **1、2、4、5、6** 个白键的右侧接缝上
（即「2 白键组 + 3 白键组」的经典键盘分群），黑键中心对齐拼缝，自墙顶下挂 1 300 mm。

每面墙 10 000 ÷ 500 = 20 块白键，10 m 内共 14 个可放黑键的接缝（最后一块白键右侧留空，避免被墙端切掉）。

### 分块与数量（按默认尺寸）
| 构件 | 数量 | 单件尺寸 |
|---|---|---|
| 白键板 | 40 块 | 492 × 1 850 × 120 mm（留 8 mm 缝） |
| 黑键条 | 28 块 | 295 × 1 300 × 25 mm（贴面） |
| 黑踢脚带 | 2 条 | 10 000 × 150 × 25 mm |
| 深色背板 | 2 张 | 10 000 × 2 000 × 18 mm（封缝） |

### 油漆估算（0.12 L/m²·遍 × 2 遍 + 10% 损耗）
- 白色面漆面积 26.26 m² → 约 **6.9 L**
- 黑色面漆面积 13.74 m²（含踢脚带）→ 约 **3.6 L**

## 二、App 里有什么

| 页 | 内容 |
|---|---|
| **3D** | 两面墙的 L 型三维模型（每块键板是独立体块，黑键真实凸出 25 mm，有日照和阴影）。六个视角：全景 / 人视 / 正视 / 俯视 / 转角 / 黑键特写（可左右滑动切换）；单指旋转、双指缩放平移、自动旋转、人形 1.7 m 比例参考；**尺寸标注**可开关；一键「存图」把当前视角存进相册 |
| **点键看尺寸** | 三维里**点任意一块键板 / 黑键 / 踢脚带** → 这块高亮（白键暖黄、黑键蓝、踢脚橙）+ 在模型上直接画出这块的宽/高尺寸线与引注；**数据区出现在屏幕下方（全宽），参数面板自动让位收起来**，所以三维画面完整不被遮挡；数据区里的「镜头定位」（或直接**双击**）把镜头拉到这块，镜头贴近时 1.7 m 人形参考会自动隐起来不挡画面。点空白处 / 点「✕」取消选中，参数面板自动回来。底部「数据」按钮可以打开总体数据面板（默认关） |
| **图纸** | 四张矢量重绘的施工图（Canvas 实时按参数出图）：① 平面图（L 型转角）② 立面展开图（20 000 × 2 000）③ 单元详图（黑键定位，含 500 / 295 / 1 300 / 3 500 / 2+3 分组）④ 剖面节点图（水平剖面 + 墙脚竖向剖面）。每张都有尺寸线、比例尺、图名栏和施工提示，可单独「存图」导出 2 倍分辨率 PNG |
| **规格** | 尺寸表、排布规则、分块数量、涂料估算、施工要点（放线 / 留缝 / 转角 / 黑键 / 表面 / 排水） |
| **底部参数** | 墙长、墙高、白键宽、黑键宽、黑键高、踢脚高、键缝、墙体厚、凸出、转角镜像，10 个参数实时联动 3D 和四张图纸；不调的时候可以点「收起」把 3D 画面腾大 |

### 单键数据卡里有什么

| 类型 | 显示的内容 |
|---|---|
| 白键板 | 尺寸 宽×高×厚（492 × 1 850 × 120 mm）、键距/拼缝 500/8、距转角范围、离地范围、第几组第几键（do / re / mi …）、右侧有无黑键 |
| 黑键条 | 尺寸 宽×高×凸（295 × 1 300 × 25 mm）、中心距转角、下沿离地 700、落在第几块白键右侧（la / la# 这种接缝命名）、第几组第几个黑键 |
| 黑踢脚带 | 通长、高度、凸出、离地范围 |

存图位置：手机相册 `Pictures/PianoWall/`（Android 10+ 无需权限）。

## 三、安装与重新打包

安装（手机连电脑开 USB 调试后）：

```bash
adb install -r PianoWall.apk
# 或把 PianoWall.apk 传到手机，用文件管理器点开安装（需允许「安装未知来源应用」）
```

重新打包（只用 Android SDK build-tools，不需要 Gradle / 联网）：

```bash
bash build.sh          # 产出 PianoWall.apk
python tools/make_icon.py   # 只重新生成图标
```

## 五、备注

- 已实机验证（vivo V2452A / Android 15，1260×2800 @3.5x）：安装、启动、WebGL 渲染、点选单块、镜头定位、存图均正常。
- 黑键高 1 300 mm（= 墙高 65%）与上传的照片实测比例（约 65–68%）以及真钢琴（63%）一致，属于耐看、好施工的比例。
- 想更接近照片里「黑键更长」的观感，把参数里「黑键高」拖到 1 500–1 700 即可，图纸和清单会同步重算。
- 转角若想让键盘图案跨过转角连续（而不是左右对称），把「转角镜像」关掉即可。
