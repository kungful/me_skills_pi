# 生活算法 LifeAlgo

一个完全离线的安卓 App：把「怎么穿、怎么吃、怎么睡、怎么练、怎么在城里/野外活下来」拆成可执行的算法。
**不联网、不需要账号、免费，所有内容内置在 APK 里。**

- 包名：`org.opensource.lifealgo`
- 版本：1.0.0（versionCode 1）
- 最低版本：Android 8.0（API 26）；编译目标 API 34
- 安装包：`dist/life-algo-1.0.0.apk`（约 17 MB）

## 功能

| 页面 | 说明 |
|---|---|
| 今日 | 每天按日期轮换 4 篇（穿搭 / 营养 / 睡眠 / 训练各一），附「今天就能做」的行动清单，可「换个方向」刷新 |
| 分类 | 12 个分类、51 篇文章，全部离线 |
| 搜索 | 标题 / 摘要 / 正文 / 标签全文检索，带评分排序 |
| 工具 | 反应力测试（简单反应 / 选择与抑制 / 目标追踪，带等级与评分）；戒除与自控（天数、冲动应对、环境加固）；用你自己的身高体重算：基础代谢 BMR、总消耗 TDEE、目标热量与三大营养素、每日饮水、睡眠周期（含 4 个就寝点 / 起床点）、1RM 估算、BMI / 腰高比、体型判定与穿搭建议 |
| 我的 | 每日提醒开关 + 时间 + 按分类筛选、深浅色主题、字号、连续打卡天数、已读篇数、收藏 |

- 每日提醒用 `AlarmManager` 精确定时（Android 12+ 自动降级为 `setAndAllowWhileIdle`），开机 / 覆盖安装后由 `BootReceiver` 自动恢复。
- 阅读进度、收藏、每日打卡存在本地 Room 数据库，不上传。
- 身体档案只存本机 SharedPreferences。

## 反应力测试

三项可当场做的测试，不进实验室也能得到一个可比较的数字：

| 测试 | 测什么 | 试次 | 评分依据 |
|---|---|---|---|
| 简单反应 | 看到变绿就点 | 5 次有效试次 | 平均反应时 + 抢跑次数 |
| 选择与抑制 | 绿点就点、红点要忍 | 12 次（8 绿 4 红，乱序） | 正确试次平均时 + 漏报 + 误点 |
| 目标追踪 | 随机位置连点 20 个目标 | 20 个目标 | 每个目标平均耗时 + 点空次数 |

- 结果给 **S/A/B/C/D/E 六档**＋「速度分 / 稳定分 / 综合分」，并标出你在档位刻度上的位置。
- 三项分别用各自的档位线：简单反应 `185/215/250/290/345 ms`，选择反应 `280/320/365/410/465 ms`，目标追踪 `520/620/740/880/1050 ms`（App 自定义的相对档位，无人群常模）。
- 错误会扣档（抢跑 0 档、选择反应 1 档、目标追踪 2 档）；稳定分由变异系数算出。
- 历史记录最多保留 80 条，存在本机，可清空；结果页会与上一次对比。
- **诚实提示已写进 App**：手机触摸采样 + 屏幕刷新 + 系统调度会额外增加 40–80 ms，此数字只能与自己纵向比较，不能当诊断依据。

## 戒除与自控

用来减少你自己不满意的重复行为（戒色是主要场景，也适用于戒无限刷、戒游戏、戒睡前刷手机）。**刻意不写市面上那一套**：不写肾虚、不写脱发、不写「禁欲提升睾酮」、不写「100 天重生」，也不做破戒自责——因为羞耻感本身就是复发最强的推动因素。

| 页签 | 做什么 |
|---|---|
| 记录 | 多目标天数（本轮连续 / 累计 / 历史最长三个数同时看）；节点进度条（1/3/7/14/30/60/90/180/365）；失误记录（触发情境 + 时间 + 可撤销）；「重新开始计时」不等于破戒 |
| 冲动来了 | 选触发情境（9 类，每类带机制解释 + 具体动作）→ 记当前强度 1–5 分 → **90 秒冲动冲浪**（4 秒吸 / 6 秒呼的呼吸圈 + 倒计时）→ 再记一次强度；自动汇总次数、平均降幅、高频触发 |
| 环境加固 | 8 项环境清单（手机不进卧室 / 清入口 / 装过滤 / 关自动播放 / 睡前固定动作 / 如果…那么… / 找一个能直说的人 / 占掉高危时段）+ 「如果…那么…」计划表单 + 就医边界说明 |

- 数据全在本机 SharedPreferences（JSON 字符串），未引入 Room 迁移；没有联网权限，没有账号。
- 档位与措辞都往「行为改变」靠：执行意图（Gollwitzer & Sheeran 2006, d≈0.65）、戒断违背效应（Marlatt & Gordon 1985）、思维抑制反弹（Wegner 1987）、自我怜悯（Leary 2007）、慢呼吸降激活。
- **几个说清楚了就不会被误导的点**：ICD-11 的 6C72 明确排除「仅出于道德不认同的痛苦」；「90 天」是社区经验值不是研究结论；冲动冲浪的精确曲线拿不出测量来源（所以只当启发式）；目前没有任何「问题性色情使用」的金标准疗法。

## 目录结构

```
app/src/main/assets/content/
  catalog.json              分类目录（名称、标语、配色、每日开关、子分类）
  articles_style.json       穿搭（4 篇）
  articles_nutrition.json   营养（5 篇）
  articles_sleep.json       睡眠（5 篇）
  articles_training.json    运动（4 篇）
  articles_reaction.json    反应力与专注（5 篇）
  articles_selfcontrol.json 戒除与自控（7 篇）
  articles_grooming.json    仪容（3 篇）
  articles_mind.json        情绪（3 篇）
  articles_urban.json       城市生存（4 篇）
  articles_wild.json        野外生存（5 篇）
  articles_digital.json     数字生活（3 篇）
  articles_science.json     原理与方法（3 篇）
```

**加内容不用改一行代码**：往对应 `articles_*.json` 里追加对象即可（字段见 `data/Models.kt`），
新增分类则在 `catalog.json` 里加一项，再新建对应 `articles_<catId>.json`。

## 构建

```bash
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
export PATH="$JAVA_HOME/bin:$PATH"
/c/Users/hua/tools/gradle-8.9/bin/gradle.bat --no-daemon assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

技术栈：Gradle 8.9 · AGP 8.6.1 · Kotlin 2.0.21 · KSP · Jetpack Compose (Material 3) · Navigation · Room · kotlinx.serialization。
依赖仓库已把阿里云镜像放在最前（`settings.gradle.kts`），适配国内网络。

调试包用固定的 `devsign.jks`（口令均为 `lifealgo`）签名，覆盖安装不会因签名变化失败。

## 装机

adb connect <手机IP>:5555
adb install -r -d dist/life-algo-1.0.0.apk
